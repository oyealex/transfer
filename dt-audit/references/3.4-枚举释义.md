# 3.4 枚举释义

报告 3.4 的固定内容，整段注入，不改写、不合并、不精简。定义分别来自 SKILL.md、问题类型.md、决策点规则.md、断言与 Mock 判据.md；这里只照抄，不新增规则。

#### 3.4.1 问题类型（见 1.2 结论表）

| 编号 | 名称 | 定义 | 计数单位 |
|---|---|---|---|
| A1 | 无测试 | 该决策点没有任何用例执行到 | 决策点 |
| A2 | 测试脱靶 | 有测试变更，但全部决策点都是「无测试」 | 对象 |
| A3 | 证据被削弱 | 断言弱化、测试删除、新增禁用、断言被注释、测例留空体、测试输入弱化 | 信号条 |
| A4 | 证据不足 | 无法判定（含结论依赖未验证的运行前提），或来源不可获取 | 决策点 |
| B1 | 无断言用例 | 用例方法体内没有任何断言调用 | 用例 |
| B2 | 断言不判别 | 断言只证明跑通了、或只校验形状，不能区分对错 | 断言条 |
| B3 | 只用交互验证 | 断言只落在假实现的调用上，没有被测对象的结果断言 | 用例 |
| C1 | 实现被替换 | 真实实现被探针、桩或 Mock 替换，用例没有执行到它 | 决策点 |
| C2 | 契约漂移风险 | 假实现的返回值与真实契约不一致 | 处 |
| D1 | 分支未观测 | 执行到了，但没有任何断言观察 | 决策点 |

容易混淆的一对：

- **A1 与 D1** 都表现为「没断言」。A1 是根本没有用例跑到这个分支，D1 是跑到了但没写断言；修法不同，一个要新建用例，一个要补断言。

同一处证据只归一个根因类型，不重复计数，因此各类数量不可相加。

#### 3.4.2 决策点类型（见 3.3 矩阵「类型」列）

| 类型 | 定义 |
|---|---|
| 条件分支 | `if` / `else if` 的每个条件 |
| 否则分支 | `else` 体内非空时单独计一个 |
| 三元取值 | `cond ? a : b` |
| 多路选择 | `switch` 的每个 `case` / `default` |
| 提前返回 | 提前 `return` / `continue` / `break` 的守卫条件 |
| 异常处理 | `catch` / `except` / 错误处理块 |
| 参数校验 | 参数校验失败路径（抛错或返回错误码） |
| 边界比较 | 显式边界常量比较；已作为条件分支计入的不重复计 |
| 兜底分支 | 显式降级、默认值、缓存未命中分支 |

**不计入的形态**：短路求值、循环进入/退出条件、条件编译、日志级别判断、裸抛异常、空值合并、框架回调注册、测试代码内部分支、纯搬移且条件文本未变的分支。

#### 3.4.3 观测状态（见 3.3 矩阵「状态」列）

| 状态 | 定义 | 计入观测率 | 计入可拦截率 |
|---|---|---|---|
| 无测试 | 没有任何用例执行到该分支 | 否 | 否 |
| 已观测 | 有判别性断言，能区分对错 | 是 | 是 |
| 部分观测 | 有断言，但不区分对错，或只覆盖了部分分支 | 是 | 否 |
| 实现被替换 | 真实实现被探针、桩或 Mock 替换，用例没有执行到它 | 否 | 否 |
| 未观测 | 执行到了，但没有任何断言观察 | 否 | 否 |
| 无法判定 | 证据不足或结构不可解析 | 不进分母 | 否 |

未被观测的决策点 = 实现被替换 + 无测试 + 未观测。三者都不计入观测率，但只有「实现被替换」算进架空率。

可拦截率的分母是全部决策点，因此「无法判定」在其中算作没拦住。

#### 3.4.4 严重度（见 1.2 结论表「严重度」列）

| 取值 | 含义 |
|---|---|
| 严重 | 基本没有证据，或证据被做了减法；修法是重做 |
| 高 | 证据存在但打不到关键处；修法是补 |
| 中 | 证据成立，但覆盖面或判别力不足；修法是加固 |

#### 3.4.5 其余标签

| 标签 | 取值 | 定义 |
|---|---|---|
| 证据来源（3.1） | 本地精确 | 本地仓 + MR 基准提交的精确差分 |
| | 本地推导 | 本地仓 + 以首个提交的父提交推导基准 |
| | 无法获取 | 仓不可达或提交缺失；只计未分析，不进分母 |
| 关联能力（3.1） | 索引级 | 仓有索引，符号级 + 调用边 |
| | 静态级 | 仓可达无索引，静态启发式 + 语义推断 |
| | 文件级 | 只有文件级信息可用，只能到文件 |
| 断言判别力（2.1） | 判别性 | 把实现改错一处会红 |
| | 结构性 | 只校验形状：大小、类型、非空、长度 |
| | 存在性 | 只证明跑通了：`assertNotNull`、`assertDoesNotThrow`、裸 `assertThrows(Exception.class)` |
| 影响档（1.4 / 2.3） | 高 | 安全 / 权限 / 鉴权、金额 / 计费 / 配额、数据写入或删除、状态迁移、对外契约 |
| | 中 | 业务计算、数据转换、字段默认值、缓存与降级 |
| | 低 | 日志、文案、埋点、调试开关、纯展示 |

影响档只用于 1.4 与 2.3 的排序，不计数、不写进证据表。

Mock 情形（2.2）：

| 类 | 情形 |
|---|---|
| 1 | 隔离外部边界（三方接口、时间、随机、文件、队列） |
| 2 | 替换同模块内部协作者 |
| 3 | 替换被测对象自身 |
| 4 | 用假对象代替值对象 |
| 5 | 假实现返回的契约与真实不一致 |
| 6 | 用交互验证代替结果断言 |
| 7 | 替换掉带业务分支的真实实现（架空） |
